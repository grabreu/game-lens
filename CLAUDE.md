# game-lens

## Repository

Games catalog API with search by meaning ("dark metroidvania") on Azure Cosmos DB, exposing four search engines (simple, full-text, vector, hybrid) as separate endpoints. Portfolio and study project; recreates Product Catalog in a games domain.

Read `README.md` before making changes.
