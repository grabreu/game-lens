# game-lens

[![License](https://img.shields.io/github/license/grabreu/game-lens?style=flat-square)](LICENSE)

Games catalog API with search by meaning ("dark metroidvania") on Azure Cosmos DB, exposing four search engines as separate endpoints: simple, full-text, vector and hybrid.

## Status

In development. Scaffold only; no features yet.

## Tech stack

Planned: .NET (Vertical Slice, Minimal API) · Azure Cosmos DB for NoSQL · Azure OpenAI embeddings · Azure App Service. TODO: confirm and document once implemented.
